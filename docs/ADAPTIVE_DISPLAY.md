# 🎨 Адаптивное отображение ячеек в VennGrid.js

**Версия:** 2.1.0  
**Дата:** 21 ноября 2025

---

## Новые возможности

### 1. 🖼️ Иконка и название в каждой ячейке

Каждая ячейка теперь отображает:
- **Иконку игры** (геймпад)
- **Название игры** (с автосокращением)
- **Дополнительную информацию** (при zoom > 1.5)

### 2. 📏 Адаптивное отображение в зависимости от zoom

Библиотека автоматически меняет детализацию в зависимости от уровня приближения:

#### Минимальный zoom (cellSize × zoom < 30px)
- Маленькая точка/индикатор
- Позволяет видеть общую картину

#### Средний zoom (30px < cellSize × zoom < 60px)
- Иконка игры (геймпад)
- Сокращенное название (до 6 символов)

#### Полный zoom (cellSize × zoom > 60px)
- Большая иконка игры
- Полное название (до 12 символов)
- **При zoom > 1.5:** Дополнительная информация
  - Жанр игры
  - Рейтинг (★)
  - Год выпуска

### 3. 🖱️ Автоматический переход на страницу игры

При клике на ячейку:
- Если задан `onCellClick` callback → вызывается callback
- Если НЕ задан callback → автоматический переход на `/games/{slug}/`

## Формат данных

Для полного использования возможностей, добавьте в данные игр:

```javascript
{
    id: 1,
    title: 'The Witcher 3',     // ОБЯЗАТЕЛЬНО - название
    slug: 'witcher3',            // ОБЯЗАТЕЛЬНО - для ссылки
    genre: 'RPG',                // Опционально - жанр
    rating: 9.5,                 // Опционально - рейтинг
    year: 2015,                  // Опционально - год
    price: 29.99                 // Опционально - цена
}
```

## API

### Автоматическое отображение

По умолчанию ячейки всегда отображаются с адаптивной детализацией:

```javascript
const venn = new VennGrid(canvas);
venn.setData(data);
// Иконки и названия отображаются автоматически
```

### Настройка callback для клика

```javascript
const venn = new VennGrid(canvas, {
    onCellClick: function(event) {
        // Кастомная обработка клика
        console.log('Клик на:', event.item.title);
        window.location.href = '/custom/' + event.item.slug;
    }
});
```

### Без callback (автоматический переход)

```javascript
const venn = new VennGrid(canvas);
// При клике автоматически откроется /games/{slug}/
```

## Примеры использования

### Пример 1: Базовое использование

```javascript
const venn = new VennGrid(document.getElementById('canvas'));

venn.setData({
    sets: [
        {
            id: 'set1',
            label: 'RPG Games',
            items: [
                {
                    id: 1, 
                    title: 'The Witcher 3', 
                    slug: 'witcher3',
                    genre: 'RPG',
                    rating: 9.5,
                    year: 2015
                }
            ]
        }
    ]
});
```

**Результат:**
- Отображается иконка + название
- При приближении видны жанр, рейтинг, год
- При клике → переход на `/games/witcher3/`

### Пример 2: С кастомным обработчиком

```javascript
const venn = new VennGrid(document.getElementById('canvas'), {
    onCellClick: function(event) {
        // Показать модальное окно вместо перехода
        showGameModal(event.item);
    }
});
```

### Пример 3: Интеграция с Django

```html
<canvas id="vennCanvas"></canvas>

<script src="{% static 'js/venn-grid.min.js' %}"></script>
<script>
const venn = new VennGrid(document.getElementById('vennCanvas'), {
    cellSize: 50,
    onCellClick: function(event) {
        // Django URL pattern
        window.location.href = "{% url 'game_detail' slug='' %}" + event.item.slug;
    }
});

// Загрузка данных с Django API
fetch('/api/venn/?genres=1,2')
    .then(r => r.json())
    .then(data => venn.setData(data));
</script>
```

## Технические детали

### Иконка геймпада

Рисуется canvas API:
- Закругленное тело геймпада
- D-pad (крестовина) слева
- Кнопки справа
- Размер адаптируется к cellSize

### Производительность

- Рендеринг оптимизирован для canvas
- Текст рисуется только для видимых ячеек
- При zoom < 0.8 используются точки (быстрее)

### Шрифты

- Название: `bold 11px Arial`
- Детали: `9px Arial`
- Короткое название: `bold 9px Arial`
