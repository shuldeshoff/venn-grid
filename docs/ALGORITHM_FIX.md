## Проблема

Визуализация не соответствовала алгоритму Godot. Данные рисовались некорректно.

## Выявленные ошибки

### ❌ Ошибка 1: Неправильная коррекция n13, n23, n123

**Файл:** `src/venn-grid.js`, строки 207-210

**Было:**
```javascript
const n123 = sorted.intersection123.length;
const n12 = sorted.intersection12.length + n123;
const n13 = sorted.intersection13.length + n123;
const n23 = sorted.intersection23.length + n123;

// ...позже
let n13_corrected = n13 - n123;
let n23_corrected = n23 - n123;
```

**Проблема:** 
- Использовались `n13_corrected` и `n23_corrected` вместо переприсваивания оригинальных переменных
- Не было коррекции самой переменной `n123` как в Godot

**Стало:**
```javascript
let n123 = sorted.intersection123.length;
const n12 = sorted.intersection12.length + n123;
let n13 = sorted.intersection13.length + n123;
let n23 = sorted.intersection23.length + n123;

// ВАЖНО: Корректируем n13, n23 и n123 как в Godot (Grid.gd строки 250-252)
n13 = n13 - n123;
n23 = n23 - n123;
n123 = (l123 * h123 > n123) ? l123 * h123 : n123;
```

**Из Godot (Grid.gd:250-252):**
```gdscript
n13 = n13 - n123
n23 = n23 - n123
n123 = l123 * h123 if l123 * h123 > n123 else n123
```

### ❌ Ошибка 2: Использование n123 вместо скорректированного значения

**Файл:** `src/venn-grid.js`, строка 242 (старая)

**Было:**
```javascript
h3 = l3 > 0 ? Math.ceil((n13_corrected + n23_corrected + n123) / l3) : 0;
```

**Проблема:** Использовался оригинальный `n123` вместо скорректированного значения

**Стало:**
```javascript
h3 = l3 > 0 ? Math.ceil((n13 + n23 + n123) / l3) : 0;
```

Теперь используются уже переприсвоенные (скорректированные) значения `n13`, `n23`, `n123`.

### ❌ Ошибка 3: Отсутствие обнуления нулевых размеров

**Файл:** `src/venn-grid.js`, строки 255-258

**Было:**
```javascript
const width = n123 > 0 ? l1 + l2 - l123 : l1 + l2 - l12;
const height = n123 > 0 ? h1 + h3 - h123 : h1 + h3 - h12;

return {
    width: Math.max(width, 0),
    height: Math.max(height, 0),
    l1, l2, l3, h1, h2, h3,
    l12, l13, l23, l123,
    h12, h13, h23, h123
};
```

**Проблема:** Не было обнуления нулевых размеров пересечений

**Стало:**
```javascript
const width = n123 > 0 ? l1 + l2 - l123 : l1 + l2 - l12;
const height = n123 > 0 ? h1 + h3 - h123 : h1 + h3 - h12;

// Обнуление нулевых размеров (из Godot Grid.gd строки 276-287)
if (h12 === 0 || l12 === 0) { h12 = 0; l12 = 0; }
if (h13 === 0 || l13 === 0) { h13 = 0; l13 = 0; }
if (h23 === 0 || l23 === 0) { h23 = 0; l23 = 0; }
if (h123 === 0 || l123 === 0) { h123 = 0; l123 = 0; }

return {
    width: Math.max(width, 0),
    height: Math.max(height, 0),
    l1, l2, l3, h1, h2, h3,
    l12, l13, l23, l123,
    h12, h13, h23, h123
};
```

**Из Godot (Grid.gd:276-287):**
```gdscript
if h12 == 0 or l12 == 0:
    h12 = 0
    l12 = 0
if h13 == 0 or l13 == 0:
    h13 = 0
    l13 = 0
if h23 == 0 or l23 == 0:
    h23 = 0
    l23 = 0
if h123 == 0 or l123 == 0:
    h123 = 0
    l123 = 0
```

## Ключевые принципы алгоритма Godot

### 1. Коррекция размеров пересечений

После вычисления `n12`, `n13`, `n23` они включают `n123` (центральное пересечение).  
Затем `n13` и `n23` корректируются вычитанием `n123`:

```
n12 = data12.size() + n123  // НЕ корректируется
n13 = data13.size() + n123  // потом: n13 = n13 - n123
n23 = data23.size() + n123  // потом: n23 = n23 - n123
```

### 2. Коррекция n123

После расчета `l123` и `h123`, значение `n123` корректируется:

```
n123 = (l123 * h123 > n123) ? l123 * h123 : n123
```

Это увеличивает `n123` до полного размера ячеек, если есть свободные места.

### 3. Общие размеры областей ВКЛЮЧАЮТ пересечения

```
n1 = data1.size() + n12 + n13 + подобласти
n2 = data2.size() + n12 + n23 + подобласти
n3 = data3.size() + n13 + n23 + подобласти
```

Это означает, что при расчете высоты и ширины области учитываются все её пересечения с другими областями.

### 4. Обнуление нулевых размеров

Если высота или ширина пересечения равна 0, обнуляются ОБА параметра:

```
if (h12 === 0 || l12 === 0) { h12 = 0; l12 = 0; }
```
