🖼️ VennGrid.js с реальными обложками

Наведите на ячейку на 0.5 секунды чтобы увидеть обложку игры

📝 Как использовать свои обложки

1. Формат данных: Добавьте поле cover с URL на JPG/PNG/WebP:
{ title: 'Game', cover: 'https://example.com/cover.jpg' }

2. Поддерживаемые форматы: JPG, PNG, WebP, GIF

3. Рекомендуемый размер: 400x600px (соотношение 2:3)

4. Без обложки: Просто не добавляйте поле cover - tooltip будет работать без картинки
